
# SeaDOTs Catalog Output (Schema)

`ogc.hosted.seadots.catalog-output` *v0.1*

Generic STAC Item and PROV-O profile for a concrete product generated by an execution.

[*Status*](http://www.opengis.net/def/status): Under development

## Description

# SeaDOTs Catalog Output

An output is a concrete STAC Item produced by an execution. It links back to the execution and to meaningful source inputs with PROV-O derived-from semantics, while remaining compatible with EDITO STAC catalog practices.

## Role in the Catalog Metadata Model

This generic building block supports the SeaDOTs catalog model described in
`data_framework/INTEROPERABILITY.md` under `Catalog Metadata Model` and
`2.2 Provenance model (Open Science)`.

## Source-property coverage gaps

This block is a generic catalog template and is not derived from a raw source
dataset. No source properties are intentionally dropped.
