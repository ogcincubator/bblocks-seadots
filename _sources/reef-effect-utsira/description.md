# Reef Effect Utsira Execution

Concrete SeaDOTs Catalog Execution record for the Utsira reef-effect biomass run.

This block instantiates the reusable [`reef-effect`](../reef-effect/) workflow. The generic catalog execution fields identify the workflow, concrete input records, and concrete output records. The local `reefEffectRun` extension preserves the Utsira-specific run details from the reef-effect workflow example: executable script, ODD model reference, evidence equation, parameter bindings, runtime details, and success criteria.

## Structure

```
properties:
  type              — Execution
  workflow          — reference to the reusable reef-effect workflow record
  application       — executable script used for this execution
  inputRecords[]    — concrete input records used by this run
  outputRecords[]   — concrete output records generated by this run
  startTime/endTime — execution window
  status            — run state
  parameters        — simple run parameter values
  reefEffectRun     — Utsira-specific execution extension
```

The `reefEffectRun.inputBindings[]` and `reefEffectRun.outputBindings[]` arrays repeat the concrete records with equation bindings and profile ids so the execution can be interpreted without inlining the input or output records.
